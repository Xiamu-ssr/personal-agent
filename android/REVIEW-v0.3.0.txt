Personal Agent Android v0.3.0 本地验收（修订第 3 轮）

本轮改动
- 编辑账号解析 accounts[].values，预填全部非 secret 字段；custom preset 自动显示保存的 host、port。
- secret 始终空白，占位为「不修改请留空」，留空或为「••••」时不放入 PUT。
- values 缺失或为 null 时沿用原来的空白表单及局部 PUT；新增账号仍使用字段 default。
- 新增脱敏账号 fixture、QQ / 手动服务器编辑场景和旧服务器回退测试。
- 版本仍为 0.3.0 / 4；本轮未改版本号或访问真实服务器。

已实现
- 云端目录和已连接项进入连接器详情，不再向聊天发送接入请求。
- cloud.custom 单独只读展示，标注「豆豆自建」；内置能力无需账号配置。
- 详情展示多账号、状态点、错误原因，支持编辑、重新测试和二次确认删除。完成操作后重新读取服务端列表。
- 根据 fields 动态生成 text、number、secret 和 select。select ≤3 个选项用分段控件，更多用下拉。
- 新增表单填入 default，按 showIf 显隐，help 支持字符串和 preset 映射。隐藏字段不提交。
- secret 使用密码框，可切换显示，关闭自动纠错和联想；表单输入仅保存在当前页面内存，不进入聊天或持久化草稿。
- 提交显示「正在验证…」，按钮和输入禁用；400 显示原因并保留输入；成功返回账号列表。
- 编辑通过 PUT 提交，secret 留空或为「••••」时省略该字段。
- 离线设备可二次确认移除。409 显示「设备在线，不能移除」，移除按钮置灰，刷新设备状态。
- 缺少 fields 的旧目录显示「即将支持」，详情禁用账号表单。
- 版本 0.3.0，versionCode 4；视觉沿用银蓝背景、半透明卡片和香槟金选中态。

编辑接口说明
更新后的 GET /api/connectors.accounts 返回脱敏 values；编辑页按 fields 预填非 secret 字段，不把「••••」填入密码框。
已有 values 时提交当前可见字段，允许清空可选备注；secret 留空时省略。缺少 values 的旧服务器仅提交用户填写的非空字段，不写入新增默认值。
账号 fixture 使用接口的 values 形状，覆盖 preset、address、label、custom host 和数值 port，并保留缺失 / null 的回退验证。
