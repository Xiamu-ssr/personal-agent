实现方式：

1. 皮肤和排版
   - 设置 → 皮肤提供银蓝、纸墨、夜幕，色块预览和单选，点击立即生效。
     SharedPreferences 独立保存本机选择，默认银蓝，不跟随系统深浅色。
   - Skin/Pal/Type 统一颜色、字号层次、正文行距和 tnum 数字排版；纸墨标题衬线，夜幕正文较轻。
   - 页签、页头、卡片、列表、用户气泡、Markdown、输入框、按钮、开关和各设置/连接/记忆页面取主题。
     删除旧的金色渐变、白色边框、页签固定颜色；卡片圆角收为 16dp，豆豆回复去掉气泡底。
   - 系统状态栏、导航栏及明暗图标跟皮肤变化。
   - 底部四页签是聊天、今日、任务、记忆；原豆豆的角色、形象和日记入口移到设置。

2. 简报
   - 在本地 HTML 响应交给解析器之前给根 html 加 data-skin，早于任何 head 脚本；切换皮肤重载文档。
   - document.documentElement.scrollHeight 换算完整高度，安全上限 2 倍屏高；不再有 75% 上限。
   - WebView 禁用内部滚动、滚动条和嵌套滚动，移动手势交给外层列表/分页，只保留正常按钮点击。
   - 高度用 180ms 动画更新，列表 key/高度缓存保持稳定；只加载可见卡片，复用和离开时暂停/释放。
   - 保留离线 origin、CSP、外部导航/网络/iframe/popup/下载/权限拦截，仅放行 doudou prompt。

3. 聊天和横滑
   - 主聊天、任务详情共用 ChatRow、Markdown、ToolRow、MessageComposer 和 ConversationScrollState。
   - 以用户手势的位置决定跟随；新消息/流式增长/键盘调整不能擅自把看历史的人拉下去。
   - 超过约一屏出现回到底部，离开底部的新增消息累计未读，点击平滑到底并清计数；发送也回到底部。
   - HorizontalPager 的连续页是聊天 → 今日简报 → 今日站点 → 任务 → 记忆，页签与分段同步。
     输入框在分页区域外；代码、宽表、附件等横向滚动内容隔离其手势；未申请系统返回手势排除区。

4. 任务
   - GET /api/jobs?limit=30 和 next/before，按本地日历分今天、近 7 天、更早，进行中排最上面。
     分页合并按 id 去重，滚到底读取更早的，next=null 结束；加载错误可重试。
   - 详情按 history 原顺序渲染：第一条 agent prompt 标“豆豆交代的”，user prompt 为用户气泡和附件，
     tool 为默认折叠工具行，text/result 为豆豆的 Markdown 回复。
   - 输入框支持与主聊天相同的文字、文件、图片、语音动作，各任务有自己的草稿。
     先 upload，再 POST 任务 send + attachments；空文字但有附件可发，失败保留草稿和已选文件。
   - 运行中独立 lifecycle coroutine 每 3 秒读取 history，终态停止；刷新复用聊天滚动规则。

5. 健康
   - 记忆页健康入口改为原生健康页面，删除 latest.json 指标读取。
   - 同步按钮 POST /api/health/sync，转圈，显示返回 note 或同步时间/设备，再 GET 刷新。
   - 今天四格，Compose Canvas 画七天柱/线；null 显示 --，缺失日期保持空槽，折线在空槽断开。
   - 周报日期范围和总结，点击 /api/briefs/item 打开不限七天的卡片页面。
   - 健康记录为两列标题、日期、两行预览，点击已有 Markdown 记忆文件页。
   - 周报/记录保留“新”标记：以本地已读时间与更新日期比较，打开后消除，后续更新再出现。

失败、修复与未采纳证据：

- 最初未读徽标被圆形裁剪，且测试读取了合并后的语义树；已修正显示和读取。
- 回底按钮隐藏时会取消自己所属的协程；改为保持协程作用域后，实际回底通过。
- 以 loading 作为分页 effect key 会取消自己的请求；改为顺序 snapshotFlow 收集后，同一 cursor 只请求一次。
- HTML 探针改变文档高度，测试偶尔在高度动画结束前点击；现等原生高度追上 scrollHeight 后点击。
  最终四轮中的最后一轮全部通过，早期失败日志/截图保存在 diagnostics/。
- 额外普通页面轮询采样读到了与 JUnit 完全相同的旧文件，没有本次启动标识，未采纳。
  因此不能宣称普通页面独立轮询采样已通过；工具在该附加步骤退出为失败，finally 已关闭模拟器。
  已在采样前删除旧文件、等待 onStop 新输出、添加 launchId/processId/clock 校验，只做了编译和语法检查。
  没有为此再次启动模拟器。acceptance.json 单独标明 7 项交互通过及这项采样未通过。
