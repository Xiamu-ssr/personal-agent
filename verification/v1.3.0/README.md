- 修复运行中活动的 started 时间字段，以及工具结果 tool_result 的解析和呈现。
- 点子与动态讨论统一为主聊天内容引用。点击只改草稿，允许空附言；发送失败保留内容，重试使用同一 clientId。历史保留点子快照，换批后的旧草稿返回明确错误。
- 删除旧点子点击执行路由；协议 2 要求 App 和 cloud 一起升级，不保留旧发送分支。

- Cloud 发布前等待空闲，离线完整备份；第一次启动因目录权限失败而自动回退，修正服务账号读取预检后发布成功。记忆、配置、配对和原生 Session 保留。
