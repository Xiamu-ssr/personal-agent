# GitHub icon

`icon.png` uses the official GitHub Invertocat path from
[`@primer/octicons` 19.40.0](https://www.npmjs.com/package/@primer/octicons/v/19.40.0),
`build/svg/mark-github-24.svg` ([upstream](https://github.com/primer/octicons)).
The package was obtained with `npm pack` in an isolated `/tmp` directory;
no dependency was added. The existing `sharp` rasterizes the unchanged path
in `#24292f` on a transparent 180 × 180 canvas with padding
(`viewBox="0 0 28 28"`, path translated by `2 2`).
