# 豆豆 1.8.0

- 修正 Mac 三列表格换行、行高重叠和末列被裁切；宽表格可横向滚动。
- 常用栏目切换复用主聊天，保留阅读位置；设置中的外观更新先释放旧聊天视图，无障碍读取同样只构建可见行。
- 统一 Mac 滚动条、选择器和附件菜单的样式；关闭菜单栏快捷聊天时释放其视图与后台刷新。
- 头像在进入页面、状态变化时播放短暂表情，空闲、离屏、后台和低电量时停止解码。
- 移除客户端重复保活与权限轮询；设备连接仍能在后台接收已授权的操作。

包含 Android APK 与 Mac 通用 DMG。已有设备直接升级，配对、会话和内容保留。Mac 使用项目本地签名，未经过 Apple 公证。
