# 0.8.3 README 素材

本目录使用作者真实账号、已配对的 macOS 豆豆 App 截图。聊天、动态、资源库和研究文档均来自实际云端数据，没有用演示内容替换界面。

| 文件 | 内容 | 隐私处理 |
| --- | --- | --- |
| `mac-chat.png` | 实际 AR 眼镜讨论及配图 | 遮住旁聊名称 |
| `mac-feed.png` | 实际动态首页 | 遮住旁聊名称 |
| `mac-feed-image.png` | 动态正文、图片和讨论入口 | 遮住旁聊名称 |
| `mac-library.png` | 实际资源库 | 遮住旁聊名称及私人构件标题 |
| `mac-document.png` | 从资源库打开的研究文档 | 遮住旁聊名称 |
| `hero.jpg` | 实际聊天截图为主体的首图 | 使用同一份已脱敏截图 |

所有截图去掉顶部 56 px 的系统远程控制标识；正文没有重绘。私人区域采用实色覆盖，不用仍能看清字形的轻度模糊。原始截图不入库。图中的新闻、研究和回答是产品内的模型输出，不作为本项目对其中事实的核验或背书。

`render-readme.py` 负责裁剪、遮挡、背景、相框和真实字体排版；无需 AI 生图。运行前需人工审查原图并核对遮挡坐标，不能将本脚本视为自动隐私识别器：

```bash
python3 docs/images/v0.8.3/render-readme.py --captures /path/to/private-captures
```

`provenance.json` 记录公开文件的尺寸、哈希和处理区域，不含私有原图路径或聊天正文。旧版演示素材保留在历史目录，当前项目首页不再引用手机截图。
