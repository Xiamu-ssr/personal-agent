# Public repository

- Keep real API keys, passwords, pairing tokens, production server addresses, private personal details, account credentials and local user paths out of source, fixtures, screenshots, logs and release notes.
- Use synthetic accounts, isolated data and example domains for public examples and screenshots. Check image pixels and metadata as well as text files before publishing.
- Runtime data, model credentials and connector accounts belong in private deployment storage. Never copy them into this repository for debugging.
- Deleting a file from the current tree does not remove older Git versions. Report that distinction accurately when cleaning previously published material.

- Ordinary conversation direction and nicknames in screenshots are acceptable. Focus privacy cleanup on actual secrets, production addresses and private account or personal details.
